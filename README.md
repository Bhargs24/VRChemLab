# VR Chemistry Lab

**Real chemistry experiments, run safely in VR, for schools and colleges without a lab.**

A physics-based virtual chemistry lab built in Unity. Students handle apparatus, measure reagents on a working weighing scale, and run reactions in a space where nothing shatters, spills, or runs out.

> **Best AR/VR Project**, World Engineering Day, VIT 2025.

## Why

Most schools cannot give every student hands-on lab time. Equipment is scarce, reagents are expensive, and safety limits what younger students can touch. VR Chemistry Lab removes those constraints. The experiment is real, the risk and the cost are not.

## Features

- Hands-on apparatus with grab, pour, and measure interactions
- A working weighing scale for accurate reagent measurement
- Physics-driven reactions and lab behavior
- Built for standalone VR headsets

## Stack

Unity, C#

## Status

Prototype, and the project that won Best AR/VR Project at VIT 2025.
